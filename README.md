# TechStack-Library 🚀

A centralized collection of technical resources, guides, documentation, cheat sheets, and learning materials covering a wide range of technologies and concepts in software development.


## 🎯 Purpose

This repository aims to:

- Build a centralized library of technical resources.
- Organize learning materials by domain and technology.
- Share useful documentation, guides, cheat sheets, and tutorials.
- Help students, developers, and tech enthusiasts learn more efficiently.
- Encourage collaboration and knowledge sharing within the developer community.

## 📚 Categories

The repository is organized into different technical domains:

| Category | Topics |
|---|---|
| Git & Version Control | Git, GitHub, branching, commits, workflows |
| Linux & Command Line | Linux commands, shell scripting, CLI tools |
| Programming Languages | Python, Java, C++, JavaScript, and more |
| Frontend Development | HTML, CSS, JavaScript, React, frontend frameworks |
| Backend Development | APIs, Django, FastAPI, Flask, Node.js, authentication |
| Databases | SQL, PostgreSQL, MySQL, MongoDB, Redis |
| Networking & Web Fundamentals | HTTP, DNS, TCP/IP, networking concepts, HTTP status codes |
| System Design | HLD, LLD, scalability, distributed systems, design patterns |
| DevOps & Cloud | Docker, CI/CD, Kubernetes, AWS, Azure, GCP |
| AI, ML & Generative AI | Machine Learning, Deep Learning, LLMs, RAG, AI frameworks |
| Testing & Quality Assurance | Unit testing, integration testing, automation, testing frameworks |
| Security | Web security, authentication, authorization, OWASP, security fundamentals |
| Developer Tools | VS Code, Postman, terminal tools, productivity tools |
| Interview Preparation | DSA, technical interview guides, common concepts, preparation resources |

## 🧭 How to Use This Repository

1. Browse the category relevant to the technology or concept you want to learn.
2. Explore the guides, documentation, cheat sheets, and resources available.
3. Use the resources as a starting point for your learning journey.
4. If you find a useful resource that isn't included, consider contributing!

## 🤝 Contributions

This repository is intended to grow through collaboration and community contributions.

You can contribute by:

- Adding useful tutorials, guides, and documentation.
- Sharing cheat sheets and technical notes.
- Adding official documentation and learning resources.
- Improving existing resources.
- Fixing broken links.
- Suggesting new categories or topics.
- Improving the repository's organization.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a contribution.

If you have resources to share or would like to collaborate, feel free to reach out!

## 📌 Contribution Guidelines

To keep the repository useful and organized:

- Ensure resources are relevant to the category.
- Prefer reliable and high-quality resources.
- Avoid duplicate submissions.
- Use descriptive filenames.
- Keep documentation clear and beginner-friendly where possible.
- Provide proper attribution and links to original sources.
- Follow the existing folder structure.

## 🌱 Community
